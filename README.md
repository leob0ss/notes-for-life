# Notes for Life

A quiet sticky-note wall for the notes worth keeping.

Open `index.html` in a browser — no build step, no accounts. Notes live in this browser’s `localStorage`.

## Features

- Infinite board you can pan and zoom
- Sticky notes with paper colors, adhesive band, and corner peel
- Select to unstick (scale up, depth blur, shadow lifts away); deselect to stick back faster
- Stack control to add notes; **start over** to clear the board

## Local

Open the file directly, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
